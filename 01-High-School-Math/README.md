# High-School Math Exercise

This exercise is part of the **Math Concepts for Developers** course.

The goal is to explore fundamental mathematical concepts and connect
them with practical Python programming.

## Topics Covered

1. **Markdown and LaTeX**
   - Writing and formatting mathematical expressions in Jupyter Notebook.

2. **Quadratic Equations**
   - Solving quadratic equations.
   - Using the quadratic formula.
   - Symbolic computation with SymPy.

3. **Plotting Functions**
   - Visualizing mathematical functions with NumPy and Matplotlib.

4. **Generalized Plotting**
   - Plotting different mathematical functions.
   - Displaying multiple functions on the same graph.

5. **Mathematical Induction**
   - Understanding proof by induction.
   - Exploring triangular numbers:

   $$
   T_n = \frac{n(n+1)}{2}
   $$

6. **Sets and Intersection over Union (IoU)**
   - Union and intersection of sets.
   - Calculating IoU.
   - Applying IoU to bounding boxes in object detection.

7. **Polynomial Roots**
   - Exploring the Fundamental Theorem of Algebra.
   - Root multiplicity.
   - Geometric behavior of roots with even and odd multiplicity.

8. **Huffman Compression**
   - Lossless and lossy compression.
   - Probability and entropy.
   - Huffman trees and binary codes.
   - Encoding and decoding data.
   - Measuring compression efficiency.
   - Comparing Huffman coding with LZ77.

## Technologies

- Python
- Jupyter Notebook
- NumPy
- Matplotlib
- SymPy

## Key Idea

The exercise demonstrates the connection between:

**Mathematics → Algorithms → Python → Machine Learning**

Mathematical concepts are not studied only theoretically, but are also
implemented, visualized, and tested with Python.
