# Math Concepts for Developers

A collection of mathematical exercises, Python implementations,
visualizations, and experiments developed while studying
**Math Concepts for Developers**.

The main goal of this repository is to connect mathematical theory
with practical software development and machine learning.

## Learning Path

### 02. Linear Algebra — 10 Solved Exercises with Python

Ten practical exercises exploring the connections between mathematical theory, numerical computation, data representation, cryptography, and machine learning. The module combines mathematical reasoning with Python implementations and visualizations.

**Exercises covered:**

1. **Polynomial Interpolation** — Constructing polynomial functions from known data points and visualizing the results.
2. **Run-Length Encoding** — Exploring a lossless data compression algorithm.
3. **Function Invertibility and Cryptography** — Understanding invertible functions and their use in cryptographic concepts.
4. **Basis Vectors in 2D** — Working with coordinate systems, vector bases, and geometric interpretation.
5. **NumPy Vectorization** — Applying array-based operations for efficient numerical computation.
6. **Linear Transformations** — Visualizing how matrices transform vectors and coordinate spaces.
7. **Images as Matrices** — Representing images numerically and performing image arithmetic.
8. **Eigenvalues and Eigenvectors** — Investigating characteristic directions of linear transformations.
9. **Diffie–Hellman Key Exchange** — Simulating shared-secret generation and exploring brute-force approaches.
10. **Principal Component Analysis (PCA)** — Exploring dimensionality reduction using covariance matrices, eigenvalues, and eigenvectors.

**Applications:** Scientific computing, computer graphics, image processing, data compression, information security, and machine learning.

**Learning outcome:** Strengthening the mathematical and computational foundations needed to understand and implement advanced algorithms in Python.

📁 [`02-Linear-Algebra`](./02-Linear-Algebra/)
