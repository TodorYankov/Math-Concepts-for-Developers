# Math Concepts for Developers

A collection of mathematical exercises, Python implementations,
visualizations, and experiments developed while studying
**Math Concepts for Developers**.

The main goal of this repository is to connect mathematical theory
with practical software development and machine learning.

## Learning Path

### 01. High-School Math

Fundamental mathematical concepts implemented and explored with Python.

Topics include:

- Markdown and LaTeX
- Quadratic equations
- Mathematical functions and plotting
- Mathematical induction
- Sets and Intersection over Union (IoU)
- Polynomial roots and multiplicity
- Probability and entropy
- Huffman compression

📁 [`01-High-School-Math`](./01-High-School-Math/)

More exercises will be added as the course progresses.

## Technologies

- Python
- Jupyter Notebook
- NumPy
- Matplotlib
- SymPy

## From Mathematics to Machine Learning

The repository follows the idea:

**Mathematics → Algorithms → Python → Machine Learning**

Each exercise combines mathematical reasoning with practical
implementation, experimentation, and visualization.
