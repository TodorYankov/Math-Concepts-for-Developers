# 02 — Linear Algebra

## Math Concepts for Developers

Practical exercises covering fundamental mathematical and linear algebra
concepts implemented and explored with Python, NumPy and Matplotlib.

### Completed Exercises

1. Polynomial Interpolation
2. Run-Length Encoding
3. Function Invertibility and Computational Performance
4. Basis Vectors and Linear Combinations
5. NumPy Vectorization and Matrix Operations
6. Visualizing Linear Transformations
7. Images as Matrices
8. Eigenvalues and Eigenvectors
9. Diffie-Hellman Key Exchange Simulation
10. Principal Component Analysis (PCA)

### Key Concepts

The exercises explore:

- vectors and vector spaces
- basis vectors and linear combinations
- matrix operations
- linear transformations
- scaling, shear, rotation and projection
- eigenvalues and eigenvectors
- dimensionality reduction with PCA
- numerical computing and vectorization with NumPy
- computational complexity through practical experiments

### PCA Results

The PCA experiments demonstrated dimensionality reduction while
preserving most of the original variance:

- **3D → 2D:** approximately **99.02%** variance preserved
- **15D → 3D:** approximately **99.77%** variance preserved
